# Evolving Skills

Evolving Skills ships two skills that work together:

- `create-skill`: the full context-engineered Create Skill package for building learning-enabled skills with progressive disclosure, context budgets, templates, workflows, references, and `learnings.md`.
- `evolve`: evolves a specific skill from its `learnings.md`, updates the correct skill surface, and clears learnings after the durable knowledge has been promoted or dismissed.

The plugin supports Codex and Claude Code from the same repository. The Codex manifest loads `codex-skills/`; the Claude Code manifest loads `claude-skills/`, so each platform gets the correct Create Skill wording and conventions.
